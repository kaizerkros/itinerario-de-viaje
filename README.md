# Itinerario Viaje

Aplicación móvil Android creada para la Evaluación Sumativa N°1 de Aplicaciones Móviles para IoT.

## Pantallas incluidas

- Login
- Registro
- Lista de viajes
- Agregar itinerario
- Detalle del viaje
- Asistente de viaje con IA

Los layouts están escritos en XML, usan recursos compartidos y cuentan con soporte de modo claro y modo oscuro.

## Cómo abrir

1. Abrir Android Studio.
2. Seleccionar **Open** y elegir esta carpeta.
3. Completar la instalación del SDK si Android Studio la solicita.
4. Ejecutar la app en un emulador o dispositivo Android.
